# Mini App design system

## Direction

«Утренний стол»: быстрый персональный рабочий экран без визуального шума и desktop-Jira паттернов.

## Tokens

- Ink `#162124` — основной текст.
- Mist `#EDF3F4` — фон приложения.
- Paper `#F9FBFB` — поверхности задач.
- Petrol `#0D6B70` — действия, active navigation и важность.
- Signal `#BF493D` — только просрочки и ошибки.
- Line `#CBD7D9` — структура и разделители.

Типографика использует системный UI sans, чтобы интерфейс оставался быстрым и нативным внутри Telegram. Иерархия строится размером и плотностью, без декоративных uppercase-labels.

## Layout

```text
┌──────────────────────────────────┐
│ дата                   + Новая   │
│ Доброе утро                       │
├──────────┬──────────┬────────────┤
│ активных │ сегодня  │ просрочено │
├──────────┴──────────┴────────────┤
│ ┌──────────────┐ ┌──────────────┐│
│ │ Входящие     │ │ Сегодня      ││ → горизонтальный Kanban
│ │ task         │ │ task         ││
│ └──────────────┘ └──────────────┘│
├──────────────────────────────────┤
│ Задачи      Сводки     Настройки │
└──────────────────────────────────┘
```

На телефоне колонки горизонтально листаются и snap-ятся; на широком экране показываются все пять. Bottom sheet — единственная заметно приподнятая поверхность.

## Principles

- Один petrol-акцент, красный не используется декоративно.
- Минимум теней; границы показывают структуру.
- Состояние задачи читается без открытия карточки.
- Нажатие открывает задачу, удержание и движение перетаскивает её.
- Все интерактивные элементы имеют keyboard focus и reduced-motion fallback.
